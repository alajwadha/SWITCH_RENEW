## Starting point

The initial evidence inventory is available in the [data snapshot](data/2026-09-28/README.md), with the full wind raster in its [GitHub Release archive](https://github.com/alajwadha/SWITCH_RENEW/releases/tag/somalia-data-2026-09-28). Start with the [source register](data/2026-09-28/manifests/source_register.csv), [conflicts](data/2026-09-28/CONFLICTS.md), [reproduction guide](data/2026-09-28/REPRODUCE.md) and [numbered work log](data/2026-09-28/WORK_LOG.md).

The next research decision is to define the question, geographic coverage, baseline year, horizon and model resolution. The [prepared advisor brief](data/2026-09-28/ADVISOR_BRIEF.md) recommends a small utility or city baseline. Metered hourly demand and reconciled operating assets/network records remain priority gaps. Build a small transparent baseline before larger studies.

Keep Somalia-specific data definitions, sources, assumptions, scenarios and methods here. Reuse shared workbench/model infrastructure; preserve the existing Kenya and tutorial models. Raw data, large outputs and live workspace files follow the repository storage and provenance rules.

The first proposed advisor checkpoint is a short research-question brief for Dan Kammen after the initial data review. Prepare the decision, evidence, alternatives and recommendation before asking the user to arrange or authorize contact.

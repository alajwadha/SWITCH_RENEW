# Research and product backlog

**Status:** recorded as part of the instruction set approved on 27 September 2026.

The ideas below are proposals. Recording them is not authorization to implement them, create new model sectors or start model runs. Follow the [repository instructions](../AGENTS.md) and [research workflow](RESEARCH_WORKFLOW.md) when an item is scoped.

## Research and product ideas backlog

These ideas require scoping, evidence and validation. Do not claim research novelty without a literature review.

| Priority | Idea | Purpose |
|---|---|---|
| First | **"Why this number?"** | Trace a displayed result through its run, calculation, assumptions and original sources. |
| First | **Documentation and consistency checks** | Detect missing assumption updates, stale results, broken references and unsupported claims. |
| First | **Evidence-quality map** | Show where results depend on observations, proxies or substantial gaps. |
| Next | **Most useful next measurement** | Identify missing information that could most change the investment decision. |
| Next | **Mini-grid-to-grid pathways** | Compare isolated operation, local connections and wider network development over time. |
| Next | **Critical-service reliability** | Examine the cost of stronger supply requirements for agreed essential services. |
| Next | **Plans resilient to difficult conditions** | Test investments against fuel disruption, poor renewable years, demand changes and delays. |
| Later | **Near-best investment alternatives** | Reveal trade-offs among plans close to the minimum-cost solution. |
| Later | **Run-change explanation** | Connect changed assumptions to changed outcomes, using controlled comparisons where needed. |
| Later | **Research package from a saved run** | Generate figures, tables, method summaries, limitations and reproduction records together. |
| Later | **New-data impact preview** | Show which parameters, runs and conclusions would be affected before adopting a source update. |
| Later | **Research-question tracking** | Link each analysis to its question, required evidence, findings and unresolved decisions. |
| Later | **Advisor briefing generator** | Assemble a concise evidence-based decision brief from existing project records. |

Prioritize a trustworthy baseline and evidence trail before adding interface complexity or new sectors.
